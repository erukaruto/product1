FAQ

Common questions

Which billing providers does Beacon support?

Beacon connects to the major subscription billing providers. You can also send events through the API if you run your own billing.

How long does the import take?

Most accounts finish within an hour. You can use the dashboard while older data is still importing.

Can I invite people outside my company?

Yes. Give advisors or investors a viewer role. They can see reports but not change settings or exports.

What happens when the trial ends?

Your account switches to read-only until you choose a plan. Nothing is deleted.

Can I export my data?

Every table has a CSV export, and the API returns the same data as JSON.
