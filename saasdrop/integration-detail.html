Data warehouse

A nightly copy of every Beacon table, ready for your own queries.

What it does

Each night Beacon writes customers, subscriptions, invoices, payments and monthly metrics to a schema in your warehouse. Tables are replaced in one step, so queries never see half-written data.

Set it up

  1. Create a user in your warehouse with write access to one empty schema.
  2. Open Settings, then Integrations in Beacon and choose Data warehouse.
  3. Paste the connection details and run the test. Beacon writes a small table and reads it back.
  4. Pick a time for the nightly copy. The first copy starts right away.
