API reference

The Beacon API returns JSON over HTTPS. All endpoints are read-only except events. Sample documentation for the demo.

Authentication

Send your API key as a bearer token. Create keys in Settings, API keys. Keep keys on servers, never in browsers or apps.

curl https://api.beacon.example/v1/customers \
  -H "Authorization: Bearer bk_live_..."

List customers

GET /v1/customers

ParameterTypeDescription
statusstringactive, trial, past_due or canceled
planstringStarter, Growth or Scale
limitinteger1 to 100, default 25
cursorstringFrom next_cursor in the previous response

Errors

Errors return a status code and a JSON body with code and message. 401 means the key is missing or revoked, 404 that the record doesn't exist, 429 that you hit the rate limit.

Rate limits

100 requests per minute per key. The X-RateLimit-Remaining header shows what's left.
